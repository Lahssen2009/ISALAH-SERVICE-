# ❄️ تبريد وتكييف حجايجي - نظام إدارة صيانة

نظام ويب احترافي بصفحة واحدة لإدارة طلبات صيانة المكيفات والثلاجات.

## 📁 هيكل الملفات

```
hajaiji-app/
├── index.html          # الصفحة الرئيسية
├── manifest.json       # إعدادات PWA
├── css/
│   └── style.css       # التنسيقات
├── js/
│   └── app.js          # المنطق البرمجي
├── assets/
│   └── (icons)         # الأيقونات
└── README.md           # هذا الملف
```

## 🚀 التشغيل

1. افتح ملف `index.html` في أي متصفح حديث
2. أو استخدم خادم محلي:
   ```bash
   python -m http.server 8000
   # ثم افتح: http://localhost:8000
   ```
